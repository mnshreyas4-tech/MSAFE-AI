# Contributing

Thank you for your interest in contributing to MSAFE-AI.

## Workflow

1. Fork the repository.
2. Create a feature branch.
3. Make your changes and keep them focused.
4. Run the relevant checks before submitting.
5. Open a pull request with a clear description.

## Code Standards

- Follow existing project conventions and file structure.
- Keep commits clear and descriptive.
- Include documentation updates when adding or changing functionality.
- Prefer small, reviewable pull requests.

## Contributor Recognition

See [CONTRIBUTORS.md](CONTRIBUTORS.md) for the current project contributors.
